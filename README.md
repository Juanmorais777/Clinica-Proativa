# Proativa Núcleo Terapêutico — Site Institucional

Site estático (HTML + CSS + JS puro), responsivo e sem dependências de build.

## Estrutura
- `index.html` — todas as seções (Hero, Quem Somos, Especialidades, Diferenciais, Depoimentos, Missão/Visão/Valores, CTA, Rodapé)
- `css/style.css` — identidade visual (roxo, lilás, azul e branco), animações e responsividade
- `js/main.js` — menu mobile, header dinâmico, animações de entrada, scrollspy
- `assets/hero.jpg` — banner principal (cérebro + árvore, folhas e borboletas)
- `assets/logo.svg` — marca provisória (substitua pela logomarca oficial mantendo o nome do arquivo)

## Como visualizar
Abra `index.html` no navegador, ou rode:
```
python3 -m http.server 8080
```
